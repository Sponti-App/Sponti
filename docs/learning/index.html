Sponti Learning Center

An internal, hands-on tour of the codebase — built lesson by lesson, grounded in the real files.

Why this exists. Understand the Sponti codebase well enough to take it from prototype to a polished, privacy-correct tester build and on to the stores — to locate, judge, and confidently change any part, and to spot wiring/UX gaps before testers do. Each lesson is short, has one takeaway, and links to the actual code.

Lessons

01 · ORIENTATION
The component map

Place any of the ~30 components into one of 6 layers — and know what each layer is allowed to do.

 02 · ONE COMPONENT, END TO END
Tracing a join

Follow joining a flare through all four layers, and see why the detail sheet holds zero business logic.

 03 · THE OTHER KIND OF COMPONENT
The create path

The "smart" feature component and the adapter layer that lets it talk to the backend — plus where the hide-able fluff lives.

 04 · CROSSING INTO THE BACKEND
Backend layering

The same join, continued through api/'s route → controller → service → model, and the rule for where logic belongs.

How to use this

Go in order — each lesson builds on the last. Do the retrieval quiz at the bottom of each from memory; that's what makes it stick. Lessons link out to the real files on GitHub.

Got a question while reading? Ask the team's Claude session — it wrote these and knows the codebase. More lessons get added as we go.
