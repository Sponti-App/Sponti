Sponti Component Map

~30 components in spa/components/, grouped into 6 layers. The lower the layer, the more reusable and dumb it is.

Provider nesting in app/layout.tsx (outermost → innermost): ThemeProvider › AuthProvider › AuthGate › ActionFeedbackProvider › NewEventDrawerProvider › AuthenticatedAppShell › {page}

1 Providers — cross-cutting context state

Wrap the whole tree. Anything that needs to be readable from anywhere lives here.

  • theme-provider.tsxlight/dark (next-themes)
  • auth-provider.tsxsession status + user
  • action-feedback.tsxtoast-style feedback
  • new-event-drawer-provider.tsxglobal "create flare" drawer

2 Shell / chrome — app frame around every page

Rendered once, not per page. Owns the bottom nav + notifications (see ADR App Shell Owns Bottom Nav).

  • authenticated-app-shell.tsxowns nav + notifications
  • bottom-nav.tsxtab bar + FAB
  • notifications-popover.tsxin-app feed
  • menu-drawer.tsx · menu-page-shell.tsxside menu + menu pages
  • auth-gate.tsx · auth-frame.tsxgates + frames auth screens

3 Views — the two home surfaces of one flare

Same flare object, filtered by timing: map = now/imminent, calendar = upcoming.

  • map-view.tsxlive flares on a map
  • calendar-view.tsx · month-calendar.tsxupcoming flares

4 Event (flare) domain — create / view / manage a flare

  • new-event-drawer.tsxcreate/edit form (large)
  • event-detail-sheet.tsxview + RSVP/join
  • event-host-card.tsx · event-avatar-stack.tsxhost + attendees
  • cancel-event-dialog.tsx · recurring-scope-modal.tsxcancel / recurring scope

5 Identity & social — people, circles, sharing

  • account-avatar.tsx · menu-profile.tsxavatar + profile summary
  • circle-stack-icon.tsxcircle visual
  • qr-share-sheet.tsx · google-auth-button.tsxQR add-friend + Google sign-in

6 UI primitives — components/ui/*, shadcn + Radix

Dumb, reusable, styled with Sponti tokens. Never contain business logic.

  • button · input · label · card · avatar · switchform + layout atoms
  • tabs · drawer · dropdown-menu · collapsible · radio-groupinteractive primitives

menu-items.ts is a data module (menu config), not a component.

Mental rule: logic flows down, events flow up. Layers 1–2 hold state and context; layers 3–5 compose features; layer 6 is pure presentation.
Source of truth: spa/components/ · app/layout.tsx
